# Quraan Arabi Academy — Official Website

Static landing site + Ijazah Mentorship page connected directly to **Supabase** (PostgreSQL + Private Storage + Live Referral Validation).

```
index.html                     Main landing page + 6-step Placement Evaluation form
quraanic-transformation.html   Founder's Ijazah Track Mentorship page & form
legal.html                     Terms, Privacy Policy, Refund Policy & Ijazah Agreement
css/style.css                  Complete styles
js/supabase-init.js            Zero-dependency Supabase REST & Storage client
js/main.js                     Form logic, pricing sync, referral verification, Journal
assets/                        Official Brand Kit logos, founder portrait, portal previews
favicon.ico                    Browser favicon
.nojekyll                      Tells GitHub Pages to serve files as-is
```

## Deploy on GitHub Pages

1. Upload **all files and folders** (`index.html`, `legal.html`, `quraanic-transformation.html`, `favicon.ico`, `.nojekyll`, `css/`, `js/`, `assets/`) to the root of the repository.
2. In GitHub: **Settings → Pages → Build and deployment → Branch `main` / `(root)`**.
3. Wait 1–2 minutes and hard-refresh (`Ctrl + Shift + R`).
